# Kebijakan Keamanan Repository Publik

Repository ini berisi materi pembelajaran dan template contoh. Jangan membuat issue publik yang memuat data rahasia atau detail infrastruktur produksi.

## Jangan publikasikan

- Password, token, API key, cookie sesi, private key, atau pre-shared key.
- Data pribadi pelanggan atau staf.
- Alamat pemasangan, koordinat, nomor kontak, atau identitas akun pelanggan.
- IP manajemen aktif, detail akses jarak jauh, konfigurasi perangkat mentah, atau peta jaringan sensitif.
- Backup perangkat produksi atau file konfigurasi yang mengandung secret.

Jika rahasia tidak sengaja terunggah, segera cabut atau rotasi rahasia tersebut. Menghapus file dari commit terbaru tidak menghapusnya dari riwayat Git. Ikuti prosedur respons insiden organisasi.
