# Checklist Pemeliharaan

- [ ] ODC/ODP dan enclosure diperiksa secara visual sesuai jadwal.
- [ ] Penutup, segel, dan pengelolaan kabel dalam kondisi baik.
- [ ] Label terbaca dan konsisten dengan catatan resmi.
- [ ] Konektor dibersihkan jika diperlukan sesuai prosedur.
- [ ] Alarm dan tren daya optik ditinjau.
- [ ] Temuan, tindakan, dan material dicatat.
- [ ] Gangguan yang memerlukan perubahan jaringan dieskalasikan.
- [ ] Foto dan catatan publik tidak memuat informasi sensitif.
