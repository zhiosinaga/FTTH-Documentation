# Checklist Instalasi

- [ ] Jalur kabel sesuai desain yang disetujui.
- [ ] Kabel terlindungi dari tekukan, tarikan, dan kerusakan.
- [ ] Konektor diperiksa dan dibersihkan dengan benar.
- [ ] Label dipasang sesuai sistem internal.
- [ ] Hasil pengukuran dicatat beserta satuan dan panjang gelombang.
- [ ] ONT/ONU diperiksa dan layanan diuji sesuai SOP.
- [ ] Area kerja dirapikan.
- [ ] Dokumentasi penyelesaian dibuat pada sistem resmi.
