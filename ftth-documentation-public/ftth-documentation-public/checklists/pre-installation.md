# Checklist Pra-Instalasi

- [ ] Perintah kerja dan otorisasi telah diverifikasi.
- [ ] Titik distribusi dan port ditetapkan melalui sistem resmi.
- [ ] Jalur kabel telah disurvei dan disetujui.
- [ ] Material dan alat ukur tersedia.
- [ ] APD dan prosedur keselamatan tersedia.
- [ ] Potensi bahaya serta izin akses telah diperiksa.
- [ ] Data pelanggan hanya digunakan pada sistem internal yang berwenang.
