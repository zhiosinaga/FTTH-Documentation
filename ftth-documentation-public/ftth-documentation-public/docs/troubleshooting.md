# Troubleshooting FTTH

| Gejala | Pemeriksaan awal | Tindakan umum |
|---|---|---|
| ONT mati | Catu daya, adaptor, stopkontak, indikator | Ikuti prosedur pemeriksaan daya; ganti komponen hanya jika berwenang |
| LOS menyala | Kondisi jalur optik, konektor, patch cord, status jaringan | Lakukan pengukuran oleh teknisi berwenang dan eskalasi jika perlu |
| Daya optik di luar batas | Alat ukur, konektor, jalur, splitter, sambungan | Verifikasi metode ukur lalu telusuri jalur sesuai SOP |
| Internet lambat | Uji kabel LAN, Wi-Fi, perangkat pengguna, status layanan | Pisahkan masalah Wi-Fi, LAN, dan akses upstream |
| Intermiten | Tekukan kabel, konektor, sambungan, catu daya, alarm | Catat waktu kejadian dan korelasikan dengan monitoring |
| Satu area terdampak | Alarm OLT, port/PON terkait, jalur distribusi | Eskalasi ke tim akses sesuai prosedur |
| Banyak area terdampak | Status POP, OLT, uplink, listrik, dan upstream | Jalankan prosedur insiden dan komunikasi layanan |
