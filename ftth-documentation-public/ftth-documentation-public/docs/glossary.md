# Glosarium FTTH

- **FTTH** — Fiber To The Home.
- **PON** — Passive Optical Network.
- **OLT** — Optical Line Terminal.
- **ONU/ONT** — Optical Network Unit / Optical Network Terminal.
- **ODF** — Optical Distribution Frame.
- **ODC** — Optical Distribution Cabinet.
- **ODP** — Optical Distribution Point.
- **OTP** — Titik terminasi optik di sisi pelanggan; istilah dan bentuk dapat berbeda antar operator.
- **Feeder** — Kabel utama dari sisi sentral menuju area distribusi.
- **Distribution cable** — Kabel distribusi dari titik distribusi menuju titik akses.
- **Drop cable** — Kabel akses menuju lokasi pelanggan.
- **Splitter** — Komponen pasif pembagi sinyal optik.
- **dBm** — Satuan daya relatif terhadap 1 mW.
- **dB** — Satuan rasio, termasuk untuk menyatakan rugi-rugi optik.
- **OTDR** — Optical Time-Domain Reflectometer.
- **VFL** — Visual Fault Locator.
- **LOS** — Loss of Signal.
- **NOC** — Network Operations Center.
