# Komponen Jaringan FTTH

| Komponen | Fungsi umum | Catatan pemeriksaan |
|---|---|---|
| OLT | Mengelola layanan PON dari sisi sentral | Port, alarm, kompatibilitas, dan kapasitas |
| ODF | Terminasi serta pengaturan serat | Label, kebersihan adaptor, radius tekuk |
| Kabel feeder | Menghubungkan sentral ke area distribusi | Jalur, kondisi kabel, dan dokumentasi |
| ODC | Titik distribusi/penempatan splitter sesuai desain | Kerapian tray, label, penutup, dan kondisi lingkungan |
| Splitter optik | Membagi sinyal optik ke beberapa cabang | Rasio, tipe, port, dan anggaran optik |
| Kabel distribusi | Membawa serat ke titik akses | Label jalur dan kondisi fisik |
| ODP | Titik distribusi dekat pelanggan | Port tersedia, penutup, kebersihan, dan label |
| Drop cable | Menghubungkan ODP ke pelanggan | Rute aman, perlindungan, dan radius tekuk |
| OTP/roset | Terminasi di lokasi pelanggan | Kerapian dan perlindungan sambungan |
| ONT/ONU | Mengubah sinyal optik menjadi antarmuka layanan | Status optik, indikator, model, dan provisioning |
| Fusion splicer | Menyambung serat dengan fusi | Kalibrasi, kondisi elektroda, dan hasil sambungan |
| Optical power meter | Mengukur daya optik | Rentang ukur, panjang gelombang, dan status kalibrasi |
| Light source | Sumber cahaya untuk pengujian rugi-rugi | Cocokkan panjang gelombang dengan metode ukur |
| OTDR | Menganalisis peristiwa dan jarak pada serat | Parameter pengujian dan interpretasi trace |
| VFL | Melacak serat untuk jarak dekat | Gunakan sesuai petunjuk dan jangan melihat langsung ke konektor |

Nama komponen dan fungsi di atas bersifat umum. Ikuti panduan produsen serta SOP operator untuk alat dan perangkat yang digunakan.
