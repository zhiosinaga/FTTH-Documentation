# Kontribusi

Kontribusi dokumentasi dipersilakan selama tetap bersifat umum dan aman untuk publik.

1. Gunakan ID, domain, dan data dummy.
2. Pastikan informasi teknis jelas serta tidak menyajikan nilai contoh sebagai standar universal.
3. Jangan menyertakan kredensial, data pribadi, atau konfigurasi produksi.
4. Periksa ejaan, tautan, dan konsistensi istilah.
5. Jelaskan sumber atau versi standar jika menambahkan persyaratan teknis tertentu.
